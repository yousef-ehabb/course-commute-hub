
Rakeb Phase 2 – Multi-Course & Multi-Vehicle Transportation System PRD
Version 2.0
Status: Draft

Overview
Phase 2 expands Rakeb to support multiple courses running on the same day with multiple transportation vehicles per course while keeping operations simple for a single coordinator.
Core Principles
• Single Coordinator role.
• Students never select a vehicle.
• Pickup stations are fixed.
• Vehicles are created according to daily attendance.
• Transportation is planned per operating day.
• Keep the MVP simple and scalable.
Business Flow
1. Students confirm attendance.
2. Coordinator reviews attendance.
3. System recommends transportation.
4. Coordinator creates today's transportation.
5. Coordinator adds one or more vehicles.
6. Coordinator starts tracking.
7. Coordinator updates vehicle status.
8. Students track vehicles.
Data Model
Course
 ├─ Students
 ├─ Stations
 └─ Operating Day

Student Model
Each student stores Course, Pickup Station, and Attendance only. Students are not permanently assigned to a vehicle.
Operating Day
Stores date, course, confirmed attendance, vehicles, statuses, and live tracking.
Vehicle Model
Fields:
- Type (Bus, Microbus, Van)
- Capacity
- Current Occupancy
- Status (Waiting, Running, Full, Arrived)
- Live Location
- Route Progress
- Notes
